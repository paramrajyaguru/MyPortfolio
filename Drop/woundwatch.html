COMPUTER VISION / STUDENT PROJECT

WoundWatch.

Tracking colour drift across post-surgical wound photographs.

THE QUESTION

What changed between photos?

Patients recovering away from a clinic may find it difficult to track changes in healing. WoundWatch explores whether image analysis can make those changes easier to review.

MY CONTRIBUTION

From image to history.

  1. Prepare the image. I worked on preprocessing and image quality assessment with Python and OpenCV.
  2. Compare observations. I explored colour drift, texture and changes over time as inputs for infection-risk prediction.
  3. Explain the output. I worked on SHAP visualizations, a patient dashboard, wound history and reports.

Project scope

This student project explores visual warning signs. Clinical performance has yet to be established.
